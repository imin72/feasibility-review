# 사업성 분석 앱 실행계획 (MVP → v1)

## 1. 목표와 범위
- 목표: `01 예상매출 → 02 투자비용 → 03 운영비용 → 04 사업성 분석` 흐름으로, 최소 입력 기반의 신뢰 가능한 분석/보고서 생성.
- 1차 범위(MVP):
  - 단계형 입력 UI
  - 표준코드 + 기본값 자동채움
  - 핵심 지표(BEP, 누적현금흐름, NPV, IRR, 회수기간)
  - PDF/PPT 보고서 초안 출력

---

## 2. 전체 일정(8주 권장)

## W1~W2: 요구사항 고정 & 데이터 표준화
### 작업
- 업종/분야/서비스 분류체계 초안 확정
- 입력항목 최소셋(필수 10~15개) 확정
- 공공/레퍼런스 데이터 소스 목록 및 갱신주기 정의
- 신뢰도 점수 정책 확정(가중치/근거표기 방식)

### 산출물
- 표준코드 사전 v0.1
- KPI/분석지표 정의서
- 데이터 소스 카탈로그

### 완료 기준
- 업종 3개 이상 샘플에 대해 입력-결과 매핑표 검증 완료

## W3~W4: 계산엔진 & 백엔드 API
### 작업
- 계산엔진 모듈화(시나리오/민감도 포함)
- 프로젝트/입력/결과 저장 API 구현
- 자동 기본값 추천 API 구현(코드·지역 기반)
- 감사로그(자동값 vs 사용자 보정값) 저장

### 산출물
- 엔진 API 명세(OpenAPI)
- 단위 테스트/회귀 테스트 세트
- 샘플 프로젝트 5건 결과 JSON

### 완료 기준
- 고정된 샘플 입력 대비 결과 오차 0(골든 파일 기반)

## W5~W6: 프론트 위저드 UI & 리포트
### 작업
- 4단계 입력 위저드 화면 구현
- 자동값 근거(출처/기준일) 툴팁 노출
- 결과 대시보드(테이블+차트) 구현
- 보고서 템플릿(PDF/PPT) 연결

### 산출물
- 사용자 플로우 데모
- 결과 화면 시안 + 실제 렌더
- 보고서 샘플 2종

### 완료 기준
- 비개발자 사용자 3명 기준, 입력 완료율 100%
- 평균 입력시간 15분 이내

## W7~W8: 검증, 파일럿, 릴리스 준비
### 작업
- 실제 케이스 파일럿(최소 10건)
- 민감도/리스크 해석 문구 고도화
- 성능/오류 로깅/권한 점검
- 운영 가이드/온보딩 문서화

### 산출물
- 파일럿 결과 리포트
- 릴리스 체크리스트
- 운영자 매뉴얼

### 완료 기준
- 파일럿 사용자 만족도 80%+
- 치명 오류 0건

---

## 3. 작업 스트림(병렬)

### A. 데이터 스트림
- 표준코드 운영 프로세스(추가/폐기/버전)
- 기준값 ETL(수집→정규화→검증→배포)
- 출처 신뢰도 점수 계산

### B. 엔진 스트림
- 지표 계산 라이브러리
- 시나리오(보수/기준/낙관)
- 민감도(단가/가동률/인건비) 분석

### C. 제품 스트림
- 단계형 입력 UX
- 결과 시각화
- 보고서 자동생성

### D. 운영 스트림
- 오류 모니터링
- 데이터 갱신 스케줄러
- 권한/감사로그

---

## 4. 역할 분담(예시)
- PM/도메인: 요구사항, 지표정의, 사용자 검증
- 데이터 담당: 표준코드, 레퍼런스 정합성, ETL
- 백엔드: 계산엔진/API/저장모델
- 프론트: 위저드/대시보드/리포트 UI
- QA: 골든 데이터 검증, 회귀테스트 자동화

---

## 5. 우선순위 백로그

## P0 (반드시)
- 표준코드 + 자동추천값 API
- 4단계 입력 위저드
- 핵심 지표 계산(BEP/NPV/IRR/회수기간)
- 결과 저장/재조회

## P1 (권장)
- 시나리오 비교(보수/기준/낙관)
- 민감도 분석 Top 3
- PDF 보고서 자동생성

## P2 (확장)
- 업종별 템플릿 마켓
- 협업(코멘트/승인)
- 외부 BI 연동

---

## 6. 리스크와 대응
- 데이터 최신성 저하 → 소스별 갱신 SLA와 알림
- 업종별 편차 과대 → 업종별 가중치/신뢰구간 제공
- 입력 피로도 증가 → 단계별 필수항목 최소화, 자동값 우선
- 결과 해석 어려움 → 경영진용 요약 카드 + 리스크 문장 자동화

---

## 7. 즉시 실행 가능한 다음 액션 (1주)
1. 샘플 업종 3개를 선정해 표준코드 매핑표 작성
2. 필수 입력 15개 후보 정의 및 제거 워크숍
3. 계산엔진 입출력 스키마(JSON) 고정
4. 화면 와이어프레임(4단계 + 결과 탭) 확정
5. 파일럿 대상 2개 부서 섭외

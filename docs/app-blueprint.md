# 사업성 분석 앱 블루프린트 (01→02→03→04)

## 1) 사용자 플로우

### STEP 01. 예상매출
- 입력(최소): 업종, 분야, 서비스종류, 지역, 목표고객 규모, 기준 단가
- 자동보정:
  - 업종별 평균 단가 범위
  - 지역별 수요/가격 보정계수
  - 시장 성장률(공공통계 기반)
- 결과:
  - 연도별 예상매출(보수/기준/낙관 3시나리오)

### STEP 02. 투자비용 (CAPEX)
- 입력(최소): 시설/장비/인테리어/개발비/보증금 중 해당 항목 체크
- 자동보정:
  - 업종·규모별 항목 템플릿 자동 생성
  - 지역별 공사/임대 단가 반영
- 결과:
  - 연도별 투자집행 계획
  - 감가상각 대상/비대상 구분

### STEP 03. 운영비용 (OPEX)
- 입력(최소): 인력구성(직군·인원), 필수 고정비 항목 확인
- 자동보정:
  - 직군별 평균 인건비(4대보험/퇴직충당 반영)
  - 임차료/전기료/유지보수비 기준치
  - 물가상승률(기본 3%) 적용
- 결과:
  - 연도별 운영비(고정/변동)
  - 원가율·판관비율

### STEP 04. 사업성 분석
- 자동 산출 지표:
  - 영업이익 = 매출 - 투자비용(연도지출분) - 운영비용
  - 영업이익률 = 영업이익 / 매출
  - 누적현금흐름
  - 단순 회수기간(Payback Period)
  - NPV, IRR
  - BEP 매출 = 고정비 / 공헌이익률
- 해석 제공:
  - 적자 전환 위험 구간
  - 민감도 상위 변수(단가, 가동률, 인건비)
  - 개선 권고안

---

## 2) 신뢰도 설계

### 데이터 신뢰도 점수 (예시)
- 공공통계/정부 데이터: 1.0
- 산업협회/공인 리포트: 0.8
- 내부 과거 실적: 0.7
- 사용자 직접 입력: 0.5

지표별로 사용한 데이터 소스를 추적해 **신뢰도 점수(0~100)**를 제공합니다.

---

## 3) 화면 구성 (MVP)
- 대시보드: 최근 프로젝트, 단계 진행률
- 입력 위저드: 01~04 단계형 폼
- 결과 탭:
  - 재무 요약
  - 연도별 테이블
  - 차트(매출/비용/영업이익/누적흐름)
  - 리스크·민감도
- 보고서 출력:
  - PPT/PDF 내보내기
  - 가정/출처 표 자동 삽입

---

## 4) 사용자 입력 최소화를 위한 규칙
- 기본값 우선(자동채움) + 사용자 보정
- 필수입력은 10~15개 핵심값 내로 제한
- 입력 누락 시 업종·지역 중앙값 자동 대체
- 모든 자동값은 근거 출처를 툴팁으로 표기
